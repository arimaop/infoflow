Идея информационного веб‑приложения

Данное веб‑приложение демонстрирует архитектуру для работы с любыми табличными или аналитическими данными. На уровне Django вы сможете:

  • подключить базу данных (SQLite, PostgreSQL и т.д.);
  • создать модели для сущностей (например, `Coin`, `Quote`, `PortfolioRecord`);
  • организовать CRUD‑интерфейсы для управления данными;
  • добавить фильтры, поиск, сортировку и пагинацию;
  • строить аналитические панели и отчёты.

Как это расширить для курсовой

  1. Спроектировать структуру базы данных под выбранную предметную область.
  2. Реализовать модели Django и миграции.
  3. Создать формы и представления для добавления/редактирования записей.
  4. Добавить авторизацию и разграничение прав (например, доступ только авторизованным).
  5. Реализовать отчёты, фильтрацию и экспорт данных (CSV/Excel).
