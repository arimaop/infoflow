# Информационное веб‑приложение на Django

Учебный проект на Django для курсовой работы по теме:  
**«Разработка информационного веб‑приложения для отображения и управления данными»**.

## Краткое описание

Проект реализован на **Python + Django** и демонстрирует:

- **слоистую архитектуру**: `urls` → `views` → `templates` → `static`;
- **готовность к подключению базы данных** (есть настройки и пример структуры данных);
- **современный UI в мягких бежевых тонах**;
- пример предметной области — **криптовалюты** (Bitcoin, Ethereum и др.).

Текущая версия использует **статический пример данных** в представлении.  
В дальнейшем можно заменить список на реальные данные из БД или внешнего API.

## Структура проекта

- `info_flow/` – корневой Django‑проект (настройки, маршруты);
- `crypto/` – приложение для отображения данных (дашборд криптовалют);
- `templates/` – общие шаблоны:
  - `base.html` – базовый макет;
  - `crypto/dashboard.html` – страница дашборда;
- `static/css/style.css` – стили (мягкая бежево‑песочная палитра);
- `requirements.txt` – зависимости Python.

> Важно: для подключения SQL Server Express используется `mssql-django`, он требует Django ветки **< 5.3**.
> Поэтому в проекте закреплён Django **5.2.x** (см. `requirements.txt`).

## Запуск проекта

1. Активировать виртуальное окружение:
   ```bash
   .\venv\Scripts\activate
   ```
2. Установить зависимости (если нужно):
   ```bash
   pip install -r requirements.txt
   ```
3. Выполнить миграции:
   ```bash
   python manage.py migrate
   ```
4. Запустить сервер разработки:
   ```bash
   python manage.py runserver
   ```
5. Открыть в браузере:
   `http://127.0.0.1:8000/`
